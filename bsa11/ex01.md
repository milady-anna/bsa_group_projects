### Задание
Для задачи 1 опишите экранные формы классификаторов и справочников.

1. Составьте список классификаторов и справочников, укажи:
- наименование классификатора/справочника;
- связанные справочники и классификаторы, которые требуются для заполнения.
2. Разработайте (нарисуйте любым способом) макеты (эскизы) экранных форм классификаторов/справочников:
- Укажите название классификатора/справочника;
- Выделите фрейм формы списка;
- Выделите фрейм операций (основных и обеспечивающих);
- Укажите вызовы операций, перехода далее и отказа от операции.
3. Опишите основные операции для классификаторов и справочников:
- права доступа по ролям к операциям;
- условия выполнения операций;
- результат операции в зависимости от условий:
- в классификаторе;
- в других частях системы.
4. Опишите обеспечивающие операции:
- сортировка, поля сортировки, состояние по умолчанию;
- фильтрация, поля фильтрации, сохранение фильтров, сообщения при отсутствии результата;
- поиск, поля поиска, точность совпадения, сообщения при отсутствии результата;
- дублирование из другой записи при добавлении (если есть);
- расчет итогов (если есть).
5. Укажите логирование:
- операции, требующие логирования;
- атрибуты, сохраняемые при логировании;
- служебные поля, требующие логирования (дата, время, пользователь, иное).

Результаты представьте в табличном виде в нескольких таблицах.
