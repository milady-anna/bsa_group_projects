Для задачи 1 для каждой экранной формы из перечисленных в Ex.04:

Разработайте (нарисуйте любым способом) макет (эскиз) экранной формы, укажи:
название формы;
фрейм главной операции;
фрейм(-ы) других операций;
вызовы операций, перехода далее и отказа от операции;
фреймы данных (списком и карточкой);
роль(-и) пользователей, которым доступен экран.
Опишите основные операции:
права доступа по ролям к операции;
условия выполнения операций;
результат операции в зависимости от условий:
над данными в текущем окне,
в других частях системы.
Опишите обеспечивающие операции:
сортировка, поля сортировки, состояние по умолчанию;
фильтрация, поля фильтрации, сохранение фильтров, сообщения при отсутствии результата;
поиск, поля поиска, точность совпадения, сообщения при отсутствии результата;
дублирование из другой записи при добавлении (если есть);
расчет итогов (если есть).
Опишите данные:
Укажите объект/класс данных;
Опишите форму списка данных:
пагинация,
краткое наименование поля,
мнемоника (если есть),
описание,
формат представления (см. ex.02, 1.с.);
Опишите форму карточки данных:
пагинация,
краткое наименование поля,
описание,
формат представления (см. ex.02, 1.с.).
Укажите логирование:
операции, требующие логирования;
атрибуты, сохраняемые при логировании;
служебные поля, требующие логирования.
